# 모먼트 (moment)

**날씨 확인부터 계산, 할 일 정리까지 한 화면에서.**

모먼트는 일상과 작업에 필요한 작은 도구를 모아 놓은 생산성 웹앱입니다. 앱 설치나 별도 회원가입 없이 브라우저에서 사용할 수 있으며, PC와 모바일 화면에 맞게 배치가 바뀝니다.

## 🌿 바로 사용하기

### 👉 [모먼트 앱 열기 — Vercel](https://moment-app-theta.vercel.app/)

[GitHub Pages에서도 사용하기](https://ssinmia-bit.github.io/moment-app/)

두 주소는 같은 앱을 제공하지만, 저장된 할 일과 메모는 주소별로 따로 관리됩니다.

위 링크는 **실제로 사용하는 앱 화면**입니다. 지금 보고 있는 GitHub 페이지는 앱의 소스 코드와 사용 설명서를 보관하는 곳입니다.

처음이라면 이렇게 시작해 보세요.

1. 앱 링크를 열어 오늘의 날씨를 확인합니다.
2. **오늘의 할 일**에 할 일을 입력하고 `+` 버튼을 누릅니다.
3. **집중 타이머**의 `집중 시작`을 눌러 25분 동안 한 가지 일에 집중합니다.
4. 필요한 계산이나 메모는 같은 화면에서 바로 처리합니다.

## 🧩 어떤 기능이 있나요?

| 기능 | 할 수 있는 일 |
| --- | --- |
| 오늘의 날씨 | 선택한 도시의 기온, 날씨 상태, 체감 온도, 습도, 풍속 확인 |
| 계산기 | 더하기, 빼기, 곱하기, 나누기, 백분율 계산 |
| 오늘의 할 일 | 할 일 추가, 완료 체크, 삭제, 진행률 확인 |
| 집중 타이머 | 25분 집중, 5분 짧은 휴식, 15분 긴 휴식 |
| 작은 메모 | 생각이나 기억할 내용을 적고 자동 저장 |
| 시계와 날짜 | 현재 기기의 시간과 날짜 확인 |

## 📖 기능별 사용 방법

### 오늘의 날씨

- 처음에는 **서울**의 날씨가 표시됩니다.
- 카드 오른쪽 위의 **도시 이름**을 누르면 검색창이 열립니다.
- `서울`, `부산`처럼 도시 이름을 입력하고 **검색**을 누릅니다.
- 마지막으로 선택한 도시는 이 브라우저에 저장됩니다.
- 날씨는 앱을 열 때와 이후 약 15분마다 새로 조회합니다. 데이터 제공 시점에 따라 실제 상황과 차이가 있을 수 있습니다.

> 날씨 조회에는 인터넷 연결이 필요합니다. 별도의 API 키나 위치 권한은 필요하지 않습니다. 검색한 도시 이름과 선택한 좌표는 날씨 제공 서비스인 [Open-Meteo](https://open-meteo.com/)에 전송됩니다.

### 계산기

- 화면의 숫자·연산 버튼을 누르거나 키보드로 입력합니다.
- `Enter` 또는 `=`: 결과 확인
- `Esc` 또는 화면의 `AC`: 계산 초기화
- `Backspace`: 입력 중인 숫자의 마지막 자리 삭제
- `+/−`: 양수와 음수 전환
- `%`: 현재 숫자를 100으로 나누기. 예를 들어 `50`에서 `%`를 누르면 `0.5`가 됩니다.

계산은 **입력한 순서대로** 처리됩니다. 예를 들어 `2 + 3 × 4 =`는 `(2 + 3) × 4`로 계산되어 `20`이 됩니다. 0으로 나누는 등 계산할 수 없는 경우에는 `오류`가 표시되며, `AC`를 눌러 다시 시작할 수 있습니다.

> 할 일이나 메모 입력창에 글을 쓰는 동안에는 계산기 키보드 단축키가 작동하지 않습니다.

### 오늘의 할 일

1. 입력창에 할 일을 적습니다.
2. `+` 또는 `Enter`를 눌러 추가합니다.
3. 끝낸 일은 왼쪽 체크박스를 선택합니다. 완료 비율과 남은 할 일 수가 함께 바뀝니다.
4. 개별 항목의 `×`를 누르면 삭제됩니다. PC에서는 항목 위에 마우스를 올리면 삭제 버튼이 나타납니다.
5. **완료 항목 지우기**를 누르면 완료한 일만 한꺼번에 삭제됩니다.

할 일은 날짜가 바뀌어도 자동으로 지워지지 않습니다.

### 집중 타이머

| 모드 | 시간 | 추천 용도 |
| --- | --- | --- |
| 집중 | 25분 | 공부, 독서, 업무 등 한 가지 일에 몰입 |
| 짧은 휴식 | 5분 | 스트레칭이나 잠깐 쉬기 |
| 긴 휴식 | 15분 | 여러 번 집중한 뒤 충분히 쉬기 |

- 모드를 고른 뒤 **집중 시작** 또는 **휴식 시작**을 누릅니다.
- 실행 중 같은 버튼을 누르면 일시 정지하고, 다시 누르면 이어서 진행합니다.
- `↻` 버튼은 현재 모드의 시간을 초기화합니다. 다른 모드를 선택해도 진행 중인 타이머가 초기화됩니다.
- 25분 집중을 끝까지 마치면 **오늘의 집중 횟수**가 1회 늘어납니다.
- 완료 메시지는 앱 화면 안에 표시됩니다. 소리나 브라우저 알림은 제공하지 않습니다.

> 새로고침하거나 탭을 닫으면 진행 중인 타이머는 초기화됩니다. 집중을 마친 횟수는 저장되며, 기기의 날짜가 바뀌면 새로 집계됩니다. 다음 집중이나 휴식은 직접 시작해 주세요.

### 작은 메모

메모 칸에 자유롭게 입력하면 바로 저장됩니다. 따로 저장 버튼을 누를 필요가 없습니다. 정상 저장되면 `저장되었어요 ✓`가 표시됩니다.

## 💾 내 데이터는 어디에 저장되나요?

할 일, 메모, 선택한 도시, 오늘의 집중 횟수는 **현재 사용하는 브라우저의 저장 공간(localStorage)**에 저장됩니다.

- 할 일과 메모는 GitHub나 별도의 앱 서버에 업로드되지 않습니다.
- 같은 기기와 브라우저에서 같은 앱 주소를 다시 열면 저장 내용을 불러옵니다.
- 다른 기기나 브라우저로 자동 동기화되지는 않습니다.
- 다운로드한 파일을 직접 열 때와 배포된 웹사이트에서 사용할 때의 저장 내용은 서로 다릅니다.
- 브라우저의 사이트 데이터를 삭제하면 저장 내용도 지워집니다. 시크릿 모드에서는 창을 닫을 때 지워질 수 있습니다.
- 브라우저 설정이나 저장 공간 제한 때문에 저장하지 못하면 앱에 안내가 표시됩니다.

**중요한 내용은 별도로 백업해 주세요.** 현재는 데이터 내보내기·복원 기능이 없습니다.

## 🖥️ 내 컴퓨터에서 실행하기

배포된 앱 링크를 사용하는 것이 가장 간단합니다. 파일을 직접 실행하고 싶다면 다음 순서로 진행하세요.

1. [저장소](https://github.com/ssinmia-bit/moment-app) 상단의 초록색 **Code** 버튼을 누릅니다.
2. **Download ZIP**을 선택해 내려받습니다.
3. ZIP 파일의 압축을 풉니다.
4. 폴더 안의 **`index.html`을 더블클릭**해 브라우저에서 엽니다.

Node.js나 별도의 프로그램 설치, 빌드 작업은 필요하지 않습니다. 다만 날씨 조회와 웹 폰트 로딩에는 인터넷 연결이 필요하며, 일부 브라우저는 파일을 직접 열었을 때 저장 기능을 제한할 수 있습니다.

## 🛠️ 파일 구성과 수정 방법

```text
moment-app/
├── index.html   # 앱 화면, 디자인, 기능이 들어 있는 파일
├── README.md    # 지금 읽고 있는 사용 설명서
└── .gitignore   # Git에 올리지 않을 파일 규칙
```

- 화면이나 기능을 바꾸려면 `index.html`을 수정합니다.
- 이 설명서를 바꾸려면 `README.md`를 수정합니다.
- 앱은 **HTML, CSS, JavaScript**로 만들어졌습니다. 날씨는 Open-Meteo API, 글꼴은 Google Fonts를 사용합니다.

### 수정한 내용을 GitHub와 앱에 반영하기

이 저장소는 GitHub Pages와 Vercel에 배포되어 있습니다. **GitHub Pages는** `main` 브랜치에 수정 내용을 푸시하면 배포가 자동으로 시작됩니다.

Git과 GitHub CLI가 설치되어 있고 로그인이 완료된 컴퓨터에서, 프로젝트 폴더의 터미널을 열어 실행하세요.

```powershell
# 1. 어떤 파일이 바뀌었는지 확인
git status

# 2. 올릴 파일 선택 (수정한 파일만 지정)
git add index.html README.md

# 3. 변경 내용을 설명하는 커밋 만들기
git commit -m "앱과 사용 설명서 업데이트"

# 4. GitHub에 올리기
git push
```

`커밋`은 변경 내용을 기록하는 것이고, `푸시`는 그 기록을 GitHub에 올리는 것입니다. 비밀번호나 API 키 같은 민감한 정보는 커밋하지 마세요.

배포 진행 상황은 저장소의 **[Actions 탭](https://github.com/ssinmia-bit/moment-app/actions)**에서 확인할 수 있습니다. 배포 완료 후에도 이전 화면이 보인다면 `Ctrl + Shift + R`로 강력 새로고침해 보세요.

배포 설정은 **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**입니다.

### Vercel 배포

Vercel 프로젝트 이름은 `moment-app`이며, 앱 주소는 **https://moment-app-theta.vercel.app/** 입니다. 빌드 과정 없이 HTML 파일을 제공하도록 `vercel.json`에 설정되어 있습니다.

현재 Vercel 배포는 CLI로 수행합니다. Vercel CLI 설치와 로그인, 프로젝트 연결이 완료된 이 프로젝트 폴더에서 다음 명령을 실행하면 수정한 앱을 배포할 수 있습니다.

```powershell
vercel deploy --prod
```

GitHub에 푸시하는 것과 Vercel CLI로 배포하는 것은 별도 작업입니다. GitHub 자동 배포를 사용하려면 Vercel 계정 설정의 **Login Connections**에서 GitHub 계정을 연결한 뒤, 다음 명령으로 저장소도 연결해야 합니다. Vercel GitHub 앱의 저장소 접근 권한 승인이 추가로 필요할 수 있습니다.

```powershell
vercel git connect https://github.com/ssinmia-bit/moment-app --yes
```

연결 완료 후에는 `main` 브랜치에 푸시할 때 Vercel 프로덕션 배포도 자동으로 실행됩니다. Vercel의 로컬 프로젝트 설정과 환경 변수 파일은 `.gitignore` 및 `.vercelignore`로 업로드에서 제외합니다.

## ❓ 자주 묻는 질문

**날씨가 표시되지 않아요.**

인터넷 연결을 확인하고 페이지를 새로고침해 보세요. 도시 이름을 눌러 다시 검색할 수도 있습니다. 서비스나 네트워크에 일시적인 문제가 있으면 잠시 뒤 다시 시도해 주세요.

**휴대폰에서 PC에 적은 메모가 안 보여요.**

메모와 할 일은 각 브라우저에만 저장되므로 기기 간에 공유되지 않습니다.

**GitHub 계정이 있어야 앱을 사용할 수 있나요?**

아니요. 앱 링크만 열면 누구나 사용할 수 있습니다. 코드를 GitHub에 올리거나 배포 설정을 바꿀 때는 계정과 권한이 필요합니다.

**앱을 수정했는데 사이트가 그대로예요.**

접속한 주소를 먼저 확인해 주세요. GitHub Pages는 `git push`와 Actions의 배포 성공 여부를 확인하고, Vercel은 CLI 배포 또는 연결된 GitHub 자동 배포가 성공했는지 확인합니다. 배포 완료 후 브라우저를 강력 새로고침해 주세요.
