# 모먼트 (moment)

계산기와 실시간 날씨를 한 화면에서 사용하는 작은 생산성 대시보드입니다.

## 기능

- 키보드 입력을 지원하는 계산기
- 도시 검색과 실시간 날씨 (Open-Meteo)
- 할 일 목록과 메모 자동 저장
- 집중 및 휴식 타이머
- 모바일 화면 지원

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드는 필요하지 않습니다.

날씨 조회와 웹 폰트 로딩에는 인터넷 연결이 필요합니다. 날씨 조회에는 API 키가 필요하지 않습니다.

할 일, 메모, 선택한 도시, 집중 횟수는 각 브라우저의 로컬 저장소에 저장됩니다. GitHub에 업로드되거나 다른 기기로 동기화되지 않습니다. 파일을 직접 열 때와 배포된 웹사이트에서 사용할 때의 저장 데이터는 서로 다릅니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시하도록 설정합니다.

## 사용 기술

HTML, CSS, JavaScript · Open-Meteo API · Google Fonts
